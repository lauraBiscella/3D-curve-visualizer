# 3D-curve-visualizer
This repository contains the project developed for the exam of the course of Computational Geometry in Università degli Studi di Milano for the academic year 2025-2026. 

The project consists in an application (developed in Unity) to visualize Bézier and Spline curves in 3D. The application let's you do this things:
- Create and modify Bézier and Spline curves
- Visualize how the curvature and twist of the curves changes according to the curve modification
